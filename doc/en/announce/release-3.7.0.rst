testrunner-3.7.0
=======================================

The testrunner team is proud to announce the 3.7.0 release!

testrunner is a mature Python testing tool with more than 2000 tests
against itself, passing on many different interpreters and platforms.

This release contains a number of bugs fixes and improvements, so users are encouraged
to take a look at the CHANGELOG:

    http://doc.testrunner.org/en/stable/changelog.html

For complete documentation, please visit:

    http://docs.testrunner.org

As usual, you can upgrade from pypi via:

    pip install -U testrunner
