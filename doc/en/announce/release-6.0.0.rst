testrunner-6.0.0
=======================================

The testrunner team is proud to announce the 6.0.0 release!

testrunner is a mature Python testing tool with more than 2000 tests
against itself, passing on many different interpreters and platforms.

This release contains a number of bug fixes and improvements, so users are encouraged
to take a look at the CHANGELOG:

    https://github.com/jacksonsr451/test-runner/tree/main/doc/en/changelog.html

For complete documentation, please visit:

    https://github.com/jacksonsr451/test-runner/tree/main/doc/en/

As usual, you can upgrade from PyPI via:

    pip install -U testrunner
